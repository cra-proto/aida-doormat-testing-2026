Obtenir un code d’accès pour la TPS/TVH – Produire votre déclaration de TPS/TVH

Vous cherchez peut-être :

  • Code d’accès à IMPÔTNET pour l’impôt des particuliers

Le code d’accès pour la TPS/TVH est un code à 4 chiffres requis pour certaines méthodes de déclaration de TPS/TVH. Il s’agit d’une clé de sécurité personnelle qui permet de vous authentifie lorsque vous n’êtes pas connecté à un compte de l’ARC. Vous ne devriez pas donner votre code d’accès à une personne non autorisée.

Votre code d’accès à la TPS/TVH reste le même pour chaque période de déclaration, sauf si vous le modifiez.

Produire une déclaration sans code d’accès

Vous n’avez pas besoin de code d’accès si vous produisez :

  • dans votre compte de l’ARC (Mon dossier d’entreprise ou Représenter un client)
  • par l’entremise d’une institution financière canadienne participante
  • par la poste

À quel moment vous avez besoin d’un code d’accès

Vous avez besoin d’un code d’accès seulement si vous produisez :

  • en ligne en utilisant le formulaire IMPÔTNET TPS/TVH (hors d’un compte de l’ARC)
  • à l’aide d’un logiciel de comptabilité tiers (Transfert de fichiers TPS/TVH par Internet)
  • au téléphone en utilisant IMPÔTEL TPS/TVH

Où trouver ou comment modifier votre code d’accès

Vous pourriez avoir reçu votre code d’accès par la poste dans les situations suivantes :

  • Vous avez déjà reçu une trousse de déclaration de la TPS/TVH par la poste.
  • Vous vous êtes inscrit à la TPS/TVH en tant que non-résident.

Si vous ne connaissez pas votre code d’accès ou si vous en avez besoin d’un nouveau, il y a 3 façons de l’obtenir ou de le modifier :

  • Trouvez votre code d’accès dans votre compte de l’ARC (compte d’entreprise seulement). Depuis octobre 2025
  • Modifiez votre code d’accès à l’aide du formulaire en ligne, à condition d’avoir produit une déclaration de TPS/TVH pour une période de déclaration se terminant au cours des 3 dernières années.
  • Si vous ne pouvez pas l’obtenir à l’aide de l’une des méthodes ci-dessus, vous pouvez obtenir ou modifier votre code d’accès par téléphone.

    Compte de l’ARC
    1. Connectez-vous à votre compte de l’ARC.
    2. Choisissez votre compte Entreprise.
    3. Choisissez TPS/TVH et votre numéro RT.
    4. À la page d’aperçu du compte de TPS/TVH, choisissez le bouton Voir les détails des déclarations.

    Les représentants qui accèdent à votre compte de l’ARC par l’intermédiaire de leur compte de représentant ne pourront pas voir votre code d’accès, peu importe leur niveau d’autorisation.


    Formulaire en ligne

    Si vous avez produit une déclaration de TPS/TVH pour une période de déclaration se terminant au cours des 3 dernières années, modifiez votre code d’accès à l’aide du formulaire en ligne.

    1. Consultez Code d’accès en ligne pour la TPS/TVH.
    2. Entrez votre numéro d’entreprise.
    3. Entrez les renseignements d’une déclaration que vous avez produite pour une période de déclaration se terminant au cours des 3 dernières années, soit :
      • la période de déclaration et le montant entré à la ligne 109 (taxe nette) si ce montant n’est pas 0 $
      • la période de déclaration et le numéro de confirmation si vous avez produit la déclaration par voie électronique
    4. Entrez le nouveau code d’accès que vous souhaitez avoir.
    5. Utilisez votre nouveau code d’accès pour produire toutes les déclarations de TPS/TVH futures.

    Téléphone

    Si vous n’êtes pas en mesure de vous connecter à votre compte de l’ARC ou d’utiliser le formulaire en ligne, appelez-nous pour obtenir ou modifier votre code d’accès :

    • Au Canada ou aux États-Unis : 1-800-959-5525
    • Au Yukon, dans les Territoires du Nord-Ouest ou au Nunavut seulement : 1-866-841-1876
    • À l’extérieur du Canada ou des États-Unis (à frais virés) : 1-613-940-8497
